# Geometry class tools

Small interactive activities for a Euclid geometry class.

- `make-it-straight.html`: try to extend a segment into a perfectly straight line (Book I, Proposition 14).
- `prop15-challenge-figure.png`: figure for the Book I, Proposition 15 challenge (two triangles in a circle).
- `beat-the-outside-angle.html`: try to make an inside angle of a triangle as big as the outside angle (Book I, Proposition 16).
- `prop17-challenge-figure.png`: figure for the Book I, Proposition 17 challenge (two perpendiculars).
